# Coaching behavior review

Review these scenarios against the current skill package. Structural tests cannot establish dialogue quality; record actual host/model outputs separately and distinguish live runs from instruction-only review.

| Scenario | Pass criterion |
| --- | --- |
| New person with no stated concern | One domain-neutral invitation; no mandatory work, biography, language selector, or weekly goal. |
| Creative aspiration alongside household overload | Explore what matters and other relevant context before the person chooses focus; no premature system-building or diagnosis. |
| "Skip the time question; let's talk about friendships" | Follow friendships; do not rephrase the time question, require a reason, or redirect to the previous topic. |
| Existing saved work goal, new home concern | Treat saved goal as context; do not overwrite or retire it merely because the conversation changes. |
| Clear task with inputs and criteria | Skip broad onboarding and address the actual request. |
| No saving, no weekly commitment | Continue useful dialogue without files or a mandatory next stage. |
| Explicit critical mode, proposed large system | Compare a smaller intervention or no action, name the tradeoff, and respect the person's choice; no literal 80/20 guarantee. |
| Person leaves critical mode or changes subject | Follow their request without continuing the scope challenge. |
| Course assignment feels burdensome | Skipping, deferment, a smaller experiment, or no assignment can succeed. |
